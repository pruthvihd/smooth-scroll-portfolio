# Smooth Scroll Portfolio

## 📌 Description

This is a modern portfolio website with smooth scrolling and animations.
It is built using frontend technologies to showcase projects, skills, and personal information.

Smooth scrolling improves user experience by allowing seamless navigation between sections instead of abrupt jumps.

---

## 🚀 Features

* Smooth scrolling navigation
* Animated sections (likely using libraries like Framer Motion)
* Responsive design
* Portfolio sections (About, Projects, Contact, etc.)

---

## 🛠️ Technologies Used

* React (Vite)
* TypeScript
* CSS / Tailwind CSS
* Framer Motion (for animations)

## ⚙️ Installation & Setup

### 1. Clone repository

git clone https://github.com/pruthvihd/smooth-scroll-portfolio.git

### 2. Navigate to folder

cd smooth-scroll-portfolio

### 3. Install dependencies

npm install

### 4. Run development server

npm run dev

---

## ⚠️ Common Issues & Fixes

### 1. Import error (@ alias not working)

Replace:
import portrait from "@/assets/portrait.jpg";

With:
import portrait from "../../assets/portrait.jpg";

---

### 2. CSS @import error

Move @import to top of CSS OR use <link> in index.html

---

### 3. Missing dependencies

Run:
npm install
